## 🚀 Quick Start

### For Users
1. **Team Call**: Team Workspace → Group Chat → Click 🎥
2. **Personal Call**: Chat → Select Contact → Click 🎥
3. **Grant Permissions**: Click "Allow" when prompted
4. **Enjoy**: Video call starts immediately!

### For Deployment
```bash
# Backend
cd BACKEND && npm install && npm run dev

# Frontend
cd FRONTEND && npm install && npm run dev
```

See `SETUP_AND_DEPLOYMENT.md` for production setup.

## 🔧 Technical Stack

### Frontend
- React 18.2+ with TypeScript
- Tailwind CSS for styling
- Framer Motion for animations
- Lucide React for icons
- Socket.io client for signaling
- WebRTC browser APIs

### Backend
- Node.js with Express
- Socket.io for real-time
- MongoDB for persistence
- JWT authentication

### Communication
- WebRTC for peer-to-peer
- Socket.io for signaling
- STUN servers for NAT
- Secure WSS protocol
