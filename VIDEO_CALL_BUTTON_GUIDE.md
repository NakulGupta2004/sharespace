# Video Call Button Locations - Quick Reference

## 🎥 Where to Find the Video Call Buttons

### 1️⃣ Team Video Call Button

**Location**: Team Workspace → Group Chat → Chat Header

**Visual Path**:
```
┌─ Team Workspace ─────────────────────────────────┐
│                                                   │
│  [Overview] [Tasks] [Inventory] [Activity]       │
│  [My Tasks] [Group Chat] ← Click Here             │
│                                                   │
│  ┌─ Group Chat ─────────────────────────────────┐
│  │  📊 Team Chat                                 │
│  │  ┌──────────────────────────────────────────┐│
│  │  │ [🎥] [Clear Chat] [⚙️ Settings]          ││ ← Green Video Icon
│  │  │                                            ││
│  │  │ Chat messages appear here...              ││
│  │  │                                            ││
│  │  │ [Type message...] [Send]                  ││
│  │  └──────────────────────────────────────────┘│
│  └──────────────────────────────────────────────┘
│
└──────────────────────────────────────────────────┘
```

**How to Use**:
1. Go to Team Workspace
2. Click "Group Chat" tab
3. Look at the chat header with "Team Chat" title
4. Click the **green 🎥 video icon** on the right side
5. Grant camera/microphone permissions if prompted
6. Video call starts! Other team members can join by clicking the same button

---

### 2️⃣ Personal 1-on-1 Video Call Button

**Location**: Chat Dialog → Contact Header

**Visual Path**:
```
┌─ Main Menu ───┐
│               │
│ [💬 Chat]  ← Click Here
│ [Team]        │
│               │
└─ Main Window ────────────────────────────────────┐
│                                                   │
│  Contacts List           Chat Dialog              │
│  ┌──────────────┐ ┌─────────────────────────────┐
│  │ Search...    │ │ [👤] John Doe   [🎥] [❌]   │←Green Video Icon
│  │              │ │                             │
│  │ [👤] User A  │ │ Messages...                 │
│  │ [👤] User B  │ │                             │
│  │ [👤] John D. │ │ [Type message...] [Send]    │
│  │ [👤] User D  │ │                             │
│  └──────────────┘ └─────────────────────────────┘
│
└──────────────────────────────────────────────────┘
```

**How to Use**:
1. Click "Chat" from main menu
2. Select a contact from the Contacts List
3. Look at the chat dialog header with their name
4. Click the **green 🎥 video icon** on the right
5. Grant camera/microphone permissions if prompted
6. Call request is sent to the recipient
7. Recipient receives incoming call notification
8. Recipient can accept or reject
9. Once accepted, video call starts!

## 🎯 Button Identification

### How to Identify the Video Call Button

| Characteristic | Details |
|---|---|
| **Icon** | 🎥 Video camera symbol |
| **Color** | Green (#16a34a) |
| **Size** | Small icon (fits in header) |
| **Hover Effect** | Becomes slightly brighter |

- ❌ NOT the Settings (⚙️) button
- ❌ NOT the Clear Chat (↻) button

## 🎬 Starting a Call - Step by Step

### Team Call
```
Step 1: Select Team Workspace
        └─> Look for your team in sidebar

Step 2: Click "Group Chat" Tab
        └─> Tab shows chat area with messages

Step 3: Find Chat Header
        └─> Shows "Team Chat" with online count

Step 4: Locate Video Button
        └─> Look for 🎥 icon in header
        └─> Should be green color
        └─> To the left of ↻ Clear Chat button

Step 5: Click the 🎥 Icon
        └─> May prompt for permissions
        └─> Click "Allow" on permission popup

Step 6: Video Call Starts!
        └─> Your camera/mic activates
        └─> Full-screen video interface loads
        └─> You can control audio/video with buttons

Step 7: Invite Others
        └─> Other team members get notification
        └─> They click same 🎥 button to join
```

### Personal Call
```
Step 1: Open Chat
        └─> Click 💬 Chat button in main menu

Step 2: Select Contact
        └─> Click on person from contacts list

Step 3: Find Chat Dialog Header
        └─> Shows contact name with avatar

Step 4: Locate Video Button
        └─> Look for 🎥 icon in header
        └─> Should be green color
        └─> To the left of ❌ Close button

Step 5: Click the 🎥 Icon
        └─> May prompt for permissions
        └─> Click "Allow" on permission popup

Step 6: Call Request Sent
        └─> Chat dialog closes
        └─> Call request sent to recipient

Step 7: Wait for Acceptance
        └─> Recipient sees incoming call notification
        └─> They can Accept or Reject

Step 8: Video Call Starts!
        └─> Once accepted, video interface loads
        └─> Both can see and hear each other
```

## 🎛️ Controls During Call

### Available Controls

```
During Any Video Call:

[Microphone Icon]  ← Click to Mute/Unmute
   Status: Blue = Audio On, Red = Audio Off

[Camera Icon]      ← Click to Enable/Disable Video
   Status: Blue = Video On, Red = Video Off

[Phone-Off Icon]   ← Click to End Call (RED)
   Status: Always Red
   Effect: Ends call immediately

Header:
[Team/Contact Name]
[Status: Connected/Connecting]
[Online Participants Count] ← Team calls only
```

## 🆘 What If I Can't Find the Button?

### Troubleshooting Steps

1. **Check You're In Right Place**
   - Team Call: Must be in "Group Chat" tab
   - Personal Call: Must have selected a contact

2. **Refresh the Page**
   - Clear browser cache
   - Reload the page
   - Try again

3. **Check Browser Zoom**
   - If zoomed in/out, some UI may be hidden
   - Reset zoom: Ctrl+0 (Windows) or Cmd+0 (Mac)
   - Try again

4. **Try Different Browser**
   - Chrome/Firefox works best
   - Try incognito/private mode
   - Disable extensions that might hide UI

5. **Check Console**
   - Press F12 to open Developer Tools
   - Check "Console" tab for errors
   - Send error messages to support

6. **Still Can't Find It?**
   - Reset browser to defaults
   - Clear all cookies/cache
   - Logout and login again
   - Contact support with screenshot

## 🎓 Tips

✅ **DO:**
- Keep camera/mic permissions enabled
- Test camera/mic before important calls
- Use headset for better audio
- Close unused applications
- Ensure good internet connection

❌ **DON'T:**
- Block camera/microphone permissions
- Try to use built-in speaker + mic (echo)
- Run bandwidth-heavy apps during calls
- Use mobile data with weak signal
- Share your desktop without consent
